# SpringCard PC/SC-like library for iOS (archived)

> **This repository is archived and remains available as a reference resource.**

The SpringCard PC/SC-like library for iOS provides access to compatible SpringCard Bluetooth Low Energy (BLE) smart card readers, including contact and contactless NFC/RFID readers operating at 13.56 MHz.

The project is no longer actively maintained. Its source code remains available to help developers explore BLE communication and smart card integration on iOS.

A companion sample application is available in the archived [iOS PC/SC-like BLE sample repository](https://github.com/springcard/ios-pcsclike-sample-ble).

When reusing this library, review and adapt it to your target iOS version, development tools and reader model.
